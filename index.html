A web framework in C, built one thread at a time.

tantu is a free, open-source framework for building web servers and APIs in C. The goal is one small, clear API that works on a Linux server, on a tiny chip like the ESP32, and in the browser through WebAssembly.

View the code on GitHub Read the roadmap

tantu is at an early stage and there is no release yet. If you want a say in how it is designed, this is the best time to join.

Why it is called tantu

Tantu is an old Sanskrit word for thread or fiber. A piece of cloth is made from thousands of threads crossing each other. The web works the same way, and so does this framework.

Instead of starting with one giant codebase, tantu grows from real projects. Each project adds one small, well-tested module, like a router or a WebSocket server. You only pull in the threads you need.

Why write a web framework in C?

Most web frameworks are tied to one kind of machine. C is different. It runs on almost anything with a processor, uses very little memory, and starts in milliseconds. That is what makes one API for all of these places possible:

  • Servers

    A fast HTTP server and API toolkit for Linux machines and VPS plans, small enough to read and understand.

  • Small devices

    The same code on microcontrollers like the ESP32, so a smart home panel or sensor can serve a real web page.

  • Browser and edge

    Compiled to WebAssembly, tantu code can run in the browser or on edge platforms close to your users.

  • AI apps

    Streaming responses, gateways for AI APIs, and vector search, planned as regular modules instead of add-ons.

C also asks for care. Mistakes with memory can become security problems. That is why every module will be built with strict warnings, tested with AddressSanitizer and UndefinedBehaviorSanitizer, and fuzz tested before it is merged.

What a tantu app should look like

This is the kind of code we are aiming for. It is a design sketch, not working code yet. Short, readable, and plain C with no magic.

Have an opinion on this API? Share it in GitHub Discussions before it is set in stone.

#include <tantu.h>

static void hello(tt_req *req, tt_res *res) {
    tt_json(res, 200, "{\"message\": \"hello\"}");
}

int main(void) {
    tt_app *app = tt_app_new();
    tt_get(app, "/hello", hello);
    return tt_listen(app, 8080);
}

Roadmap

tantu is built in eight phases. Each phase is a set of useful projects, and each project leaves behind a module for the framework.

  1. Foundation Next up

    A small HTTP server, a JSON toolkit and a URL router.

    Modules: core, json, router

  2. Real-time

    A WebSocket chat server, a live dashboard with server-sent events, and a simple publish and subscribe broker.

    Modules: websocket, stream, bus

  3. AI

    A gateway for AI APIs with caching and rate limits, a local model server, vector search, and document search.

    Modules: client, serve, vector

  4. Edge and WebAssembly

    A WASI build for edge platforms, a browser target, and an edge cache.

    Modules: port, wasm, cache

  5. IoT

    A web server for the ESP32, a time-series API for sensor data, and a bridge between MQTT and HTTP.

    Modules: embedded, timeseries, adapters

  6. Security

    Login with JWT, OAuth2 and passkeys, a web application firewall, and automatic HTTPS with Let's Encrypt.

    Modules: auth, guard, tls

  7. Modern protocols

    HTTP/3 over QUIC for faster connections on mobile networks.

    Module: h3

  8. Developer tools

    A command line tool to start new projects, hot reload while you work, and bindings for Python, Node.js and PHP.

    Modules: cli, dev, bindings

Frequently asked questions

Is tantu ready to use?

Not yet. tantu is at an early stage and there is no release. The roadmap and design are public, and the first module, a small HTTP server, is the next step.

Is tantu free?

Yes. tantu uses the MIT license, so you can use it in personal and commercial projects, change it, and share it.

What does the name tantu mean?

Tantu is an old Sanskrit word for thread or fiber. A web is made of many threads, and the framework is made of many small modules.

Can I run tantu on shared hosting?

Usually not. Most shared hosting plans only run PHP and do not let you start your own server. You can run tantu on your own computer, on a VPS, or on a small device like the ESP32.

Why build a web framework in C and not Rust or Go?

C runs almost everywhere, from tiny chips to large servers, and it compiles to WebAssembly. That makes one API for all of these places possible. Memory safety is handled with strict code review, sanitizers and fuzz testing.

How can I help with tantu?

Start a conversation in GitHub Discussions, report a bug or idea in Issues, or send a pull request. Help with documentation and design reviews is just as welcome as code.
